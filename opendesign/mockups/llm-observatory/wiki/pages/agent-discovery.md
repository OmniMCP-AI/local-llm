The hosted site will publish public pages with stable URLs and Markdown companions. Every format will identify the same evidence release, including charts and tables.

## Public discovery formats

- [robots.txt standard](https://www.rfc-editor.org/rfc/rfc9309) for crawler preferences, with a sitemap for canonical public pages.
- [llms.txt proposal](https://llmstxt.org/) for a concise index of public Markdown, methods, release information, and citations.
- [API catalog discovery](https://www.rfc-editor.org/rfc/rfc9727) when the documented read-only API is live. Versioned MCP tools will query the same evidence service.

This prototype illustrates the content and routes. The hosted crawl files and endpoints are deployment deliverables. See [For agents](#agents) and the [evidence guide](#wiki/evidence-guide).
