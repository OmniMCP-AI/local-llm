Open Feedback on any page to describe a question or missing observation. The local prototype gives immediate guidance and keeps the note on this device. For a public request, use the GitHub link.

## Include what lets somebody reproduce it

- A page, model artifact, hardware build, runtime version, and exact workload are often more useful than a general suggestion.
- File a public [GitHub issue](https://github.com/OmniMCP-AI/local-llm/issues/new) with only what you choose to share.
- Read [what counts as evidence](#wiki/evidence-guide) or [browse the source catalog](#catalog) before filing a missing listing.
