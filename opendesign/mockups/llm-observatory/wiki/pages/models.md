The model family name is a starting point. Quantization, runtime and context length affect fit and whether two runs can be compared.

## Find a comparison

- Search source-linked repositories in the [model catalog](#catalog/models).

- Open [Qwen2.5 7B Instruct](#models/qwen25-7b), [Qwen2.5 14B Instruct](#models/qwen25-14b), or [Llama 3.1 8B Instruct](#models/llama31-8b).
- Use the [benchmark method](#wiki/benchmark-method) before comparing speed figures. For a machine-first workflow, open [machine profiles](#machines).

Use the ranking for the selected artifact, context and backend. The map compares paired 4K and 32K results and highlights the current model. Select a point or rank to follow the pair across views. The exact result links to its machine profile when available.
