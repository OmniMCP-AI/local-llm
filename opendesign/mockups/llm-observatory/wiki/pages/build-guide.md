Start with the workload, price range, and software you can actually run. A build sheet is a plan until its exact components and compatibility are confirmed.

## Before choosing parts

- Check GPU clearance, PCIe slots, power connectors, cooling, PSU headroom, and the operating system and driver requirements.
- Distinguish dedicated VRAM from host or unified memory. Check what the application can use after reservations.
- Compare the complete machine price in the same market, condition, and capture window.

## After a change

- Save substitutions as a different configuration. Previous run results apply to the original configuration.
- Check [benchmark method](#wiki/benchmark-method) for the problem you are trying to solve and [Price watch](#prices) for the quote scope.
- Browse example plans for the [RTX 4090](#machines/rtx-4090), [RTX 3090](#machines/rtx-3090), or [Mac mini M4 Pro](#machines/m4-pro).
