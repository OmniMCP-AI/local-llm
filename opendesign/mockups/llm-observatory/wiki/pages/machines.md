A machine profile describes the complete configuration behind a run. Check memory, cooling, power, and the exact board or system variant before treating a configuration as interchangeable.

## Compare a build

- Open the [RTX 4090](#machines/rtx-4090), [RTX 3090](#machines/rtx-3090), or [Mac mini M4 Pro](#machines/m4-pro) reference profile.
- Use [Plan a local build](#wiki/build-guide) to record what has to be checked before ordering.
- Start with the [model library](#models) if you already know which artifact you want to run.

Use the profile ranking to see which tested models decode faster at the selected context. The map shows paired 4K and 32K results across the demo cohort and highlights the current machine. Select a pair in either view to inspect its result and find the corresponding model profile. Throughput across different model tokenizers does not establish a task-quality ranking.
