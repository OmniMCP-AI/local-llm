## How to read the catalog

- **Retained** shows every attributed photo and the original source or license recorded by the snapshot. The gallery column preserves each recorded scope, including render, family and capacity caveats.
- **Reusable candidate** identifies a particular photo or photographic still with an original record, a credited creator, a stated open license and an applicable board identity. A row with a family-level identity can use a labeled example. Keep the depicted edition visible in the credit. Use the exact part number or evidence of the same specimen when the row calls for it. Apply the specific license and record edits before publishing.
- **Publisher photo** points to a first-hand hardware review or report that identifies the physical board. The source is useful for permission requests and visual identification. The audit found no verified reuse grant for those images.
- **Manufacturer** points to product imagery or an official gallery. The imagery can include renders or illustrative family views. Treat the link as reference evidence while checking any file-specific use terms.
- **Discovery** points to a potentially useful file, video, listing or related board with unresolved identity, image evidence or permission. A dash means the audit has no entry in that column. A row with dashes in all three evidence columns is unresolved.

For modified cards, the enclosure or cooler may be shared with a stock variant. Require evidence that ties the pictured specimen to its modified capacity, such as a visible part label plus the publisher’s matching hardware inspection or a dated bench result. All sixteen records with modification evidence still need a cleared catalog photo. The Kinology gallery and BIM Computing listings supply seller leads for several exact advertised configurations. Gamers Nexus documents the workshop RTX 4090 conversion. Kate’s report identifies tested 80 GB CMP 170HX devices, with photo-to-specimen linkage still needed. The original creator’s Colorful RTX 2080 Ti board has conflicting reported capacities. T10 remains unresolved at the identity level.

## Discovery and evidence

- Search began with Wikimedia Commons file and category records, linked Wikipedia imagery and the Sams.Help photo index. Attribution and license for Commons candidates were checked against the original file record using the Commons Action API `imageinfo` fields `url`, `mime` and `extmetadata`. Preserve archived source-video citations for review stills. The broader Commons title search began returning HTTP 429 during discovery, so it was used only for the files or queries that returned records. [Commons reuse guidance](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia), [GTX 16 Series Wikipedia image](https://en.wikipedia.org/wiki/GeForce_GTX_16_series), [Sams.Help discovery index](https://sams.help/gpu-photo-credits/).
- Open-web image discovery returned mixed sellers and publishers for the RTX 2080 SUPER. Its original Wccftech review identifies the physical Gigabyte Gaming OC board, and a separate Commons photo documents the same model under an explicit open license. The original record governs each particular image. ## Reproduce the inventory

Run against the local review database. The snapshot filter makes the baseline independent of changes to the current snapshot pointer. Omitting the photo `data` field keeps the result text-only. [Catalog schema](../opendesign/mockups/llm-observatory/catalog-pg.sql), [photo registry](../opendesign/mockups/llm-observatory/catalog-gpu-photo-ids.json), [asset and attribution index](../opendesign/mockups/llm-observatory/hardware-assets/assets.json).

```sql
BEGIN READ ONLY;

SELECT g.id,
       g.document->>'name' AS name,
       g.document->>'variant' AS variant,
       g.document#>'{vendorSpec,gallery}' AS gallery,
       (SELECT jsonb_agg(photo - 'data')
        FROM jsonb_array_elements(coalesce(g.document->'photos', '[]'::jsonb)) AS photo) AS photos,
       g.document->'modification' AS modification
FROM fastest_catalog.gpu AS g
WHERE g.snapshot_id = 'd2e12ad4697c127ddbb06a87863e208fcc947b1417e88efe042277fb38cb194d'
ORDER BY g.id;

ROLLBACK;
```
